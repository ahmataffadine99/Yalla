# Application mobile Yalla

L'application Flutter client/chauffeur est prévue après la stabilisation des premiers parcours et du contrat OpenAPI de l'API.

Ce dossier n'est pas encore un projet Flutter compilable : le SDK Flutter n'est pas installé dans l'environnement de préparation. Il sera initialisé avec Flutter lorsque cette phase commencera, plutôt que de maintenir manuellement des fichiers natifs incomplets.
